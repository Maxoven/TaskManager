# AI-портал «Помощник» — ai.ecoestate.tv

Простой чат с ИИ-помощником для сотрудников без технической подготовки. Вход — аккаунтом Task Manager.
У каждого человека своя изолированная среда: помощник (OpenCode), облачный браузер, папка с файлами.

## Что видит человек

Один экран в стиле Task Manager: слева разговоры, в центре переписка и поле «Напишите задачу обычными словами…»,
справа сворачиваемая панель «Экран помощника» (живой экран облачного браузера, можно кликать и печатать самому)
и «Файлы» (загрузить / скачать). В поле ввода — скрепка, микрофон (диктовка средствами браузера) и выбор, кто отвечает:
GLM-5.3 или DeepSeek Flash. Режимов, терминала и настроек нет. Интерфейс OpenCode наружу не отдаётся.

## Сервисы

Кнопка «Сервисы» показывает, с чем помощник работает от имени человека. Task Manager подключён всегда; рабочая почта —
если пароль от неё совпал с паролем Task Manager при входе, иначе человек вводит пароль от почты в «Сервисах».
Остальные сервисы (`gateway/src/services.js`, список `CATALOG`) подключаются кнопкой «Подключить»: шлюз добавляет MCP-сервер
в настройки OpenCode человека, получает у OpenCode адрес страницы входа и открывает её в облачном браузере; человек входит
на «Экране помощника», обратный адрес (127.0.0.1 внутри среды) ловит сам OpenCode. «Добавить другой сервис» — любой MCP по адресу,
с ключом или со входом. Сервисы Google (Gmail, Календарь, Диск) показаны как «Скоро»: им нужен свой OAuth-клиент Google.
Через зарубежный туннель доступны и сервисы, закрытые для России (Notion, GitHub, Miro, Zapier) — в каталог они пока не добавлены.

## Как устроено

```
браузер ── nginx (ai.ecoestate.tv) ── gateway (Node, pm2 «aiportal», 127.0.0.1:3200)
                                          │  вход: POST /api/auth/login Task Manager
                                          │  /api/oc/* — узкий список запросов к OpenCode среды
                                          │  /api/services/* — каталог сервисов (MCP) и вход в них
                                          │  /screen/*  — noVNC среды
                                          ▼
                    среда человека: контейнер aiportal-u<ID> (Docker + gVisor, сеть aiportal)
                      opencode serve :4096 · Chromium на Xvfb · x11vnc → websockify :6080 · Playwright MCP
                      /home/user — диск-файл человека (/srv/aiportal/images/u<ID>.img, лимит места)
                                          │
                    прокси моделей и MCP (gateway, 172.30.0.1:3210 — виден только средам)
                      /zai/v1, /deepseek/v1   — подставляет настоящие ключи, пускает только glm-5.3 и deepseek-flash,
                                                пишет расход по людям в gateway/data/usage.jsonl
                      /mcp/taskmanager        — MCP Task Manager и почты от имени вошедшего человека
```

- **Модели.** Человек выбирает GLM-5.3 (по умолчанию) или DeepSeek Flash — выбор действует на разговор и запоминается; все подручные (субагенты `general`, `explore`, `browser`, `verifier`) — DeepSeek Flash.
  Ключи лежат только в `gateway/.env` на сервере; в среде — лишь её собственный токен.
- **Изоляция.** gVisor (свой ядро-посредник), сеть без доступа к серверу, другим средам и локальным сетям; наружу — интернет
  (кроме порта 25). CPU, память, число процессов и место на диске ограничены.
- **Выход в интернет.** Браузер и программы среды ходят на сайты через шлюз (`gateway/src/egress.js`, тот же порт 3210):
  российские адреса (зоны .ru/.рф и сети России по списку RIPE) — напрямую с этого сервера, всё остальное — через туннель `ssh -D`
  на свой зарубежный сервер (`EGRESS_SSH`, отдельный пользователь без оболочки, ключ `~/.ssh/aiportal_tunnel`). Так открываются сайты,
  недоступные из России, и работает встроенный поиск OpenCode (Exa). Туннель держит сам шлюз; если он лёг — сайты идут напрямую.
  К самому серверу, его службам, другим средам и внутренним сетям через прокси попасть нельзя.
- **Память.** Первые две одновременно работающие среды получают по 2 ГБ, третья — 1,5 ГБ (место определяется при запуске среды).
  Сторож (`gateway/src/memwatch.js`) раз в 10 секунд смотрит память каждой среды: держит в облачном браузере не больше 6 вкладок,
  при 80% потолка закрывает фоновые вкладки, при 92% перезапускает браузер — чтобы среду не убило целиком вместе с задачей.
- **Сон.** Среда поднимается при входе (3–5 секунд) и засыпает после `IDLE_MINUTES` без запросов; файлы, разговоры
  и входы на сайтах в облачном браузере сохраняются на диске человека.
- **Инструкция помощнику** — `sandbox/opencode-config/ultra-code.md`: простой язык без терминов, всё делать самому,
  перед необратимым спрашивать «да», большие задачи дробить и раздавать подручным параллельно, проверять результат.

## Папки

| Папка | Что там |
|---|---|
| `server/setup-root.sh` | Однократная подготовка сервера от root: Docker, gVisor, сеть и правила, диски людей, nginx, сертификат |
| `sandbox/` | Образ среды: Dockerfile, запуск процессов, настройки OpenCode (`/etc/opencode`) |
| `gateway/` | Шлюз: вход, запуск сред, прокси к OpenCode, прокси моделей, мост к MCP Task Manager, страницы портала |
| `deploy.sh` | Выкладка (root не нужен): код, `.env`, образ среды, перезапуск pm2 |

## Настройки (`gateway/.env` на сервере)

`SESSION_SECRET`, `DEEPSEEK_API_KEY`, `ZAI_API_KEY` создаёт `deploy.sh` (ключи берёт из `deepseek.txt` и `glm.txt` в корне репозитория).
Необязательные: `MAX_ACTIVE` (сколько сред одновременно, по умолчанию 3), `IDLE_MINUTES` (30), `SANDBOX_MEMORY_MB` (2048, первым
`SANDBOX_BIG_SLOTS` = 2 средам) и `SANDBOX_MEMORY_SMALL_MB` (1536, остальным), `MEMWATCH_TRIM_AT` (0.80), `MEMWATCH_RESTART_AT` (0.92), `MEMWATCH_MAX_TABS` (6),
`SANDBOX_CPUS` (1.5), `SANDBOX_DISK_GB` (5, для новых людей), `MAX_UPLOAD_MB` (100), `EGRESS_SSH` (`user@host` зарубежного сервера;
не задан — все сайты напрямую), `EGRESS_FORCE_TUNNEL` / `EGRESS_FORCE_DIRECT` (домены через запятую: всегда через туннель / всегда напрямую).

## Полезное

```bash
./deploy.sh                      # выложить всё; SKIP_IMAGE=1 — только шлюз и страницы
OPENCODE_VERSION=2.4.1 ./deploy.sh   # другая версия OpenCode (скачивается с GitHub, сверяется SHA256)
ssh taskmanager 'pm2 logs aiportal --lines 50'
ssh taskmanager 'docker ps --filter label=aiportal.user'          # кто сейчас работает
ssh taskmanager 'tail -5 ~/aiportal/gateway/data/usage.jsonl'     # расход моделей
ssh taskmanager 'pm2 logs aiportal --nostream --lines 200 | grep egress'   # туннель и сколько запросов куда ушло
ssh taskmanager 'sudo /usr/local/sbin/aiportal-volume grow 7 20'  # дать человеку №7 20 ГБ
```
